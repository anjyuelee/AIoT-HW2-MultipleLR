    方法說明

    1. 讀取資料略過含缺值的列；整欄都是數字的視為數值特徵，其餘視為類別。
    2. One-hot類別依字母排序，丟掉第一個作為基準類別（drop first），避免與截距共線。
    3. 切分隨機資料以固定 seed（mulberry32 + Fisher–Yates 洗牌）依比例切出測試集；設定 groupColumn 時改依群組切分。
    4. 交叉驗證特徵選擇只在訓練集做 5-fold CV；每個 fold 都重跑特徵選擇與 OLS，以平均 CV RMSE 和 1-SE 法則選方法與 k，再用完整訓練集重擬合：
      • Forward SFS：從只有截距開始，每一步加入讓訓練集 RSS 最小的特徵。
      • RFE（Backward）：從全部特徵開始，每次刪掉標準化係數絕對值最小的特徵。
      • Lasso：X、y 標準化後沿 L1 正則化路徑（λ 由大到小），依特徵第一次出現非零係數的順序排名。
      • ElasticNet：同 Lasso，但懲罰項為 L1 與 L2 各半（l1_ratio = 0.5）。
      • Exhaustive：每個 k 列舉所有組合，取訓練集 RSS 最小者（特徵超過 15 個時停用）。
    5. 評估模型選定後才在測試集計算 RMSE、R²、MAE；測試集只作最終評估，不參與選模。
    6. 統計推論參數估計、Adjusted R² 與 F 檢定都是訓練集 OLS 的結果（同 statsmodels）；VIF = 1 / (1 − R²ⱼ)，R²ⱼ 為該特徵對其餘特徵回歸的 R²。

    以最低 CV RMSE + 1 SE 為門檻，在符合門檻的模型中選最少特徵數；RMSE vs k 圖中的測試集曲線僅供參考，不用於選模。

    CRISP-DM：商業目標與成功標準

      1. 商業理解確立要預測的目標（target）與事前訂定的業務成功標準。
      2. 資料理解讀取 CSV，檢視筆數、欄位型別與缺值（見「欄位與型別」）。
      3. 資料準備略過缺值列、類別欄 one-hot（drop first），以固定 seed 隨機或依群組切分訓練集與測試集。
      4. 建模在訓練集內做 5-fold CV；每個 fold 重跑特徵選擇與 OLS，以 1-SE 法則選方法與 k，再用完整訓練集重擬合。
      5. 評估只在模型選定後比較測試集 RMSE、R²、MAE，並檢查係數顯著性、VIF 與殘差。
      6. 部署以純前端靜態網頁發布（可部署到 GitHub Pages），用即時預測器套用模型。
